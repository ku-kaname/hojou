# 機能一覧

- **工程**: 要件定義工程
- **作成者**: 利用者
- **作成日**: 2026-09-11
- **最終更新日**: 2026-09-18

---

## 一般利用者が行える操作
| No | 機能 | 説明 |
|---|---|---|
| F01 | ユーザー登録 | ユーザー名・パスワードを登録する |
| F02 | ログイン | ユーザー名・パスワードで認証しJWTトークンを発行する |
| F03 | ユーザー情報取得 | 自分のユーザー情報を取得する |
| F04 | ユーザー更新 | 自分のユーザー名・パスワードを更新する |
| F05 | ユーザー削除 | 自分のユーザーを論理削除する（削除フラグをTrueに更新） |
| F06 | 復習情報登録 | 復習項目・学習日・詳細を登録し、5回分の復習スケジュールを自動生成する |
| F07 | 復習情報取得 | 自分の復習情報一覧を取得する |
| F08 | 復習情報更新 | 自分の復習項目・詳細・対応済みフラグを更新する |
| F09 | 復習情報削除 | 自分の復習情報および紐づく復習スケジュールを削除する |

---

## 管理者が行える操作
| No | 機能 | 説明 |
|---|---|---|
| F10 | 全ユーザー情報取得 | 全ユーザーの情報一覧を取得する |
| F11 | ユーザー更新（管理者） | 任意のユーザー情報を更新する |
| F12 | ユーザー削除（管理者） | 任意のユーザーを論理削除する |
