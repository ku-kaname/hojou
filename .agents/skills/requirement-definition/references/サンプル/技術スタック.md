## フロントエンド

| 項目 | 技術 | 用途 |
|---|---|---|
| 言語 | TypeScript | 型安全なフロントエンド開発 |
| フレームワーク | React 18.x | 画面（SPA）構築 |
| ビルドツール | Vite | 開発サーバー・本番ビルド |
| ルーティング | react-router-dom | 画面遷移（ログイン・マイページ・復習情報一覧等） |
| HTTP通信 | fetch API（標準搭載） | バックエンドAPI呼び出し。追加ライブラリ不要のため採用 |
| テスト | Vitest + React Testing Library | Reactコンポーネントの単体テスト |
| 配信 | Nginx | ビルド成果物（静的ファイル）のコンテナ配信 |
