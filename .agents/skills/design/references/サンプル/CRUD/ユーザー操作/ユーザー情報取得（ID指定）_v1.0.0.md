### 処理概要

#### 【目的】
- ユーザーIDをもとにユーザー情報を1件取得する。

#### 【処理概略】
- 入力値のユーザーIDに一致する、削除されていないユーザー情報をUSERテーブルから取得する。
- 取得したユーザー情報を返却する。

## ○処理詳細

### 1. ユーザー情報取得

- (1) USERテーブルから取得する。

  ```sql
  SELECT
    id,               -- ユーザー情報．ユーザーID
    user_name,        -- ユーザー情報．ユーザー名
    hashed_password,  -- ユーザー情報．ハッシュ済みパスワード
    delete_flag,      -- ユーザー情報．削除済みフラグ
    admin_flag,        -- ユーザー情報．管理者フラグ
    created_at,        -- ユーザー情報．作成日
    updated_at         -- ユーザー情報．更新日
  FROM user
  WHERE
    id = :user_id              -- ユーザー情報．ユーザーID
    AND delete_flag = :delete_flag;  -- ユーザー情報．削除済みフラグ
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | ユーザーID | - | - | - |
  | 取得内容 | ユーザー名 | - | - | - |
  | 取得内容 | ハッシュ済みパスワード | - | - | - |
  | 取得内容 | 削除済みフラグ | - | - | - |
  | 取得内容 | 管理者フラグ | - | - | - |
  | 取得内容 | 作成日 | - | - | - |
  | 取得内容 | 更新日 | - | - | - |
  | 検索条件 | ユーザーID | ○ | 入力値．ユーザーID | - |
  | 検索条件 | 削除済みフラグ | ○ | False | - |
