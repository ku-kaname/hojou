# 実装 Codex指摘・再鑑時チェックリスト

> **注記**：本チェックリストが前提とするCodex運用は、公開版v1時点では動作未検証の実験的機能です。Claude運用を正式サポート対象とし、Codexでの動作確認が取れ次第、正式サポートへ格上げします。

Codex（GPT-5）によるレビュー指摘・再鑑で実際に発生した指摘ミスを基にした、実装工程向けのセルフチェック項目。技術スタックに依存しない、指摘・再鑑プロセス上の観点を扱う。人手（Codexによる自己再鑑を含む）でのレビュー時に使用する。

## MVP対象・対応時期の判定

- [ ] 設計工程で既にバックログ対応・対応時期先送りと確定済みの論点（アクセス制御の検証範囲、認証系のレート制限方式等）を、実装工程で改めて現段階の対応必須として指摘していないか
- [ ] 実装コードの変更を求める前に、対応するレビュー指摘表・判断根拠書・バックログで現在のMVP対象か確認したか
- [ ] 技術的に望ましい実装であることと、現在対応が必須であることを分けて判定したか

## 再鑑時の確認

- [ ] 一度MVP対象外・バックログと確定した事項を、再鑑で別表現に置き換えて再指摘していないか
- [ ] 対応不要と確定した論点を除外一覧として管理し、追加指摘候補と照合したか
- [ ] 対応済み件数・未解消件数・追加指摘件数は、MVP対象外を除いた同じ母集団で比較しているか

## 実際に発生した指摘ミス（要約）

複数の実装ファイルにまたがる認証・アクセス制御関連の対応拡大（検証範囲の拡大、レート制限の追加等）を、いずれも現段階での実装必須として指摘したが、対応する設計工程のレビューで既にバックログ対応と確定済みだった。
