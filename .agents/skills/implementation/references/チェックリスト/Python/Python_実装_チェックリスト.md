# 実装 チェックリスト（Python）

## 例外処理

- [ ] `except Exception` のような広範なハンドラが、ビジネスロジック用の例外処理を意図せず捕捉していないか

## 型アノテーション

- [ ] バリデーション条件が引数の型と整合しているか（例：`datetime | None` 型のフィールドに `== ""` のような文字列比較は到達不能コードになる）

## 出力処理のインジェクション対策

- [ ] AI生成値・利用者入力を、外部ツールが特別な意味を持たせて解釈する文字列（ZIPエントリパス、Excelセル値、Markdown等）へ埋め込む前に、出力先フォーマットの構文規則を洗い出し無害化しているか
- [ ] 同一モジュール内で類似の出力処理（ファイル書き出し等）が並存する場合、無害化処理を共通ヘルパー関数へ集約し、個別実装ごとの対応漏れを防いでいるか
- [ ] サニタイズ処理を1回導入して終わりにせず、「その検証で防ぎきれないケースが他にないか」を段階的に見直したか

## docstring・コメントの表記

- [ ] Windows形式パスをdocstring・コメントに書く際、通常文字列のバックスラッシュがエスケープシーケンスとして解釈されないよう、raw文字列またはスラッシュ表記を使用しているか
- [ ] 定型的な記述パターン（docstring内パス表記等）に指摘が入った場合、1件目の対応時に同一パターンの全箇所を横断検索し、まとめて修正したか
