# 結合テスト チェックリスト（React）

> **注記**：本チェックリストが対象とするReactは、公開版v1時点では動作未検証の技術スタックです。FastAPIを正式サポート対象とし、Reactでの動作確認が取れ次第、正式サポートへ格上げします。

## 列挙型定数・型定義への追随

- [ ] ステータス値・質問項目一覧など複数の画面・テストから参照される列挙型定数を変更した際、その定数を参照する既存の結合テスト仕様書・テストコードを横断検索してから変更作業を完了としたか

## 異常系到達経路の網羅

- [ ] 結合テストが「画面内操作を経て特定の状態へ到達する」構成に偏っている場合、外部要因（ブラウザ再読み込み・直接URL遷移・外部リンク等）で直接その状態に到達するケースも確認したか

## ビルド・Lintの実行確認

- [ ] 結合テスト工程の完了判定に、`npm run build`・`npm run lint`等の品質確認コマンドを実際に実行しエラーなく完了することの確認を含めたか
