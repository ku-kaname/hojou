## ○処理詳細

### 1. ユーザー情報登録

- (1) USERテーブルへ登録する。

  ```sql
  INSERT INTO user (
    user_name,        -- ユーザー情報．ユーザー名
    hashed_password,  -- ユーザー情報．ハッシュ済みパスワード
    admin_flag,        -- ユーザー情報．管理者フラグ
    created_at,        -- ユーザー情報．作成日
    updated_at         -- ユーザー情報．更新日
  ) VALUES (
    :user_name,
    :hashed_password,
    :admin_flag,
    :today,
    :today
  );
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |

  | 登録内容 | ユーザー名 | ○ | 入力値．ユーザー名 | - |
  | 登録内容 | ハッシュ済みパスワード | ○ | 入力値．ハッシュ済みパスワード | - |
