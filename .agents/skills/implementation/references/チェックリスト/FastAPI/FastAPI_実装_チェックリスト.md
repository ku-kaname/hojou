# 実装 チェックリスト（FastAPI）

## ルーティング

- [ ] ルーターを分割する場合は `APIRouter` + `app.include_router()` を使っているか（`FastAPI()` を複数インスタンス化しない）

## ファイル間の依存関係

- [ ] `main.py`・`crud.py`・`schemas.py` は相互に影響するため、1ファイルの変更時は他ファイルへの影響を確認したか

## 層構造・ファイル構成の一貫性

- [ ] 巨大ファイル（`main.py`等）を段階的に分割する場合、着手前に分割後の最終的なファイル構成粒度（単一ファイルのままにする層／機能単位でサブディレクトリ化する層）を確定したか
- [ ] エンドポイント関数がservices層を経由せず、`crud.py`・`security.py`等のデータアクセス層を直接呼び出していないか（エンドポイント→services→crudの一方向を守っているか）
- [ ] 層構造のルール違反が1件見つかった場合、同種の構造を持つ他の全エンドポイント関数を横断的に確認し、機械的に是正したか

## 認証エンドポイントのセキュリティ実装

- [ ] レート制限を実装する際、実際のデプロイ構成（リバースプロキシ有無・プロセス数）でIP取得方法とカウンター共有方式が機能するか確認したか
