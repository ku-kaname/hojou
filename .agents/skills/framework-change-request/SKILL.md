# hojou自体の変更依頼

`hojou`（工程ガイド・ツール本体）は、これを利用する各プロジェクト側から直接編集しない。変更が必要な場合は、`ku-kaname/hojou`へissueを作成する窓口を通す。

## 手順

1. 依頼を作成する前に、`../../../変更依頼/変更履歴・非採用一覧.md`を確認し、同種の依頼が既に対応済み・非採用と判定済みでないか確認する。
2. 未対応であれば、`references/依頼ルール.md`のフォーマット・運用フローに従ってissueを作成する。

- 変更履歴・非採用一覧（対応状況の確認）：`../../../変更依頼/変更履歴・非採用一覧.md`
