### 処理概要

#### 【目的】
- ユーザーに紐づく復習項目一覧を、各復習項目の復習管理情報（復習回・予定日・対応状況）とあわせて取得する。

#### 【処理概略】
- 入力値のユーザーIDをもとに、REVIEWテーブルとREVIEW_MANAGEMENTテーブルを結合して取得する。
- 取得した内容を復習項目一覧リストとして返却する。

## ○処理詳細

### 1. 復習項目取得

- (1) REVIEWテーブルとREVIEW_MANAGEMENTテーブルを結合して取得する。

  ```sql
  SELECT
    review.review_item,             -- 復習情報．復習項目
    review.description,             -- 復習情報．復習内容詳細
    review.study_date,              -- 復習情報．学習日
    review_management.review_time,  -- 復習管理情報．復習回
    review_management.review_date,  -- 復習管理情報．復習予定日
    review_management.done_flag     -- 復習管理情報．対応済みフラグ
  FROM review
  JOIN review_management
    ON review.user_id = review_management.user_id      -- 結合条件：復習情報．ユーザーID = 復習管理情報．ユーザーID
    AND review.review_id = review_management.review_id  -- 結合条件：復習情報．復習項目ID = 復習管理情報．復習項目ID
  WHERE
    review.user_id = :user_id;  -- 復習情報．ユーザーID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 復習情報．復習項目 | - | - | - |
  | 取得内容 | 復習情報．復習内容詳細 | - | - | - |
  | 取得内容 | 復習情報．学習日 | - | - | - |
  | 取得内容 | 復習管理情報．復習回 | - | - | - |
  | 取得内容 | 復習管理情報．復習予定日 | - | - | - |
  | 取得内容 | 復習管理情報．対応済みフラグ | - | - | - |
  | 検索条件 | 復習情報．ユーザーID | ○ | 入力値．ユーザーID | - |
