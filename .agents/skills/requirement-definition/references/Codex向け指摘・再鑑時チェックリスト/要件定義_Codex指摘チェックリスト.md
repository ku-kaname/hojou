# 要件定義 Codex指摘・再鑑時チェックリスト

> **注記**：本チェックリストが前提とするCodex運用は、公開版v1時点では動作未検証の実験的機能です。Claude運用を正式サポート対象とし、Codexでの動作確認が取れ次第、正式サポートへ格上げします。

Codex（GPT-5）によるレビュー指摘・再鑑で実際に発生した指摘ミスを基にした、要件定義工程向けのセルフチェック項目。技術スタックに依存しない、指摘・再鑑プロセス上の観点を扱う。人手（Codexによる自己再鑑を含む）でのレビュー時に使用する。

## MVP対象・対応時期の判定

- [ ] 非機能要件（バックアップ頻度・保管先・RPO/RTO等）の運用値確定を、開発・検証段階で対応必須の事項と誤認していないか。実ユーザーを扱うMVP公開時の運用設計で決定する事項であれば、現段階での対応必須指摘から外したか
- [ ] 技術的なリスクが存在することと、現在のMVP受入条件に含まれることを分けて判定したか
- [ ] 指摘候補を「現在のMVP対象」「MVP対象外・バックログ」「対応要否未確定」のいずれかに分類し、要件定義書・判断根拠書・バックログ・引継ぎ資料と照合したか

## 再鑑時の確認

- [ ] 一度MVP対象外・バックログと確定した事項を、再鑑で「未解消」「記載不足」等の別表現に置き換えて再指摘していないか
- [ ] 対応不要と確定した論点を除外一覧として管理し、追加指摘候補と照合したか
- [ ] 対応済み件数・未解消件数・追加指摘件数は、MVP対象外を除いた同じ母集団で比較しているか

## 実際に発生した指摘ミス（要約）

非機能要件のレビューで、運用値（バックアップ頻度・保管先・RPO/RTO等）を開発・検証段階で確定すべき事項として指摘したが、実際はユーザー判断により対応時期が明確に分けられていた。
