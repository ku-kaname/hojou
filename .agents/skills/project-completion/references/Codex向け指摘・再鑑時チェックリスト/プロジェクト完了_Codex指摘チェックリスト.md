# プロジェクト完了 Codex指摘・再鑑時チェックリスト

> **注記**：本チェックリストが前提とするCodex運用は、公開版v1時点では動作未検証の実験的機能です。Claude運用を正式サポート対象とし、Codexでの動作確認が取れ次第、正式サポートへ格上げします。

Codex（GPT-5）によるレビュー指摘・再鑑で実際に発生した指摘ミスを基にした、全工程完了時（全工程横断の再鑑・完了判定）向けのセルフチェック項目。技術スタックに依存しない、指摘・再鑑プロセス上の観点を扱う。人手（Codexによる自己再鑑を含む）でのレビュー時に使用する。

## 完了判定の件数・記述の扱い

- [ ] 全工程再鑑の引継ぎ資料で、MVP対象外と確定済みの事項を件数差・未解消件数・完了阻害要因として扱っていないか
- [ ] バックログ一覧の記述精緻化（対応対象の機能数表現、対応範囲の詳細化等）を、現在工程で対応必須の追加指摘にしていないか
- [ ] 将来バックログの記述をさらに精緻化できるという理由だけで、完了判定を保留・追加指摘へ差し戻していないか
- [ ] 完了資料へ記載する件数・状態が、レビュー指摘表・作業管理・バックログ・引継ぎ資料の間で一致しているか
- [ ] 「追加指摘なし」の判定は、MVP対象の受入条件についてのみ行っているか。将来バックログが残ることと、現在の全工程が完了していることを両立する状態として扱っているか

## 実際に発生した指摘ミス（要約）

全工程再鑑の引継ぎ資料で、MVP対象外の事項を含む件数差を追加指摘として扱った。また、バックログ一覧の対応対象機能数の表現や、対応範囲の記述精緻化の余地を、現在工程の追加指摘として一時的に提示したが、いずれも将来バックログの記述精緻化にすぎず、確定前に撤回した。
