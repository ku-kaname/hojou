### 処理概要

#### 【目的】
- ユーザー情報を更新する。

#### 【処理概略】
- 変更前ユーザー名をもとにUSERテーブルを検索し、入力があった項目のみ更新する。
- 更新後のユーザー情報を返却する。

## ○処理詳細

### 1. ユーザー情報更新

- (1) USERテーブルを更新する。

  ```sql
  UPDATE user
  SET
    user_name = :user_name_after,               -- ユーザー情報．ユーザー名
    hashed_password = :hashed_password_after,    -- ユーザー情報．ハッシュ済みパスワード
    updated_at = :today                          -- ユーザー情報．更新日
  WHERE
    user_name = :user_name_before;               -- ユーザー情報．ユーザー名
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | ユーザー名 | - | 入力値．変更後ユーザー名 | 入力が無い場合、更新しない |
  | 更新内容 | ハッシュ済みパスワード | - | 入力値．変更後ハッシュ済みパスワード | 入力が無い場合、更新しない |
  | 更新内容 | 更新日 | ○ | 入力値．現在日時 | - |
  | 検索条件 | ユーザー名 | ○ | 入力値．変更前ユーザー名 | - |
