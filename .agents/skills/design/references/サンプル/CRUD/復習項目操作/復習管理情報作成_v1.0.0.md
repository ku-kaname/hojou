### 処理概要

#### 【目的】
- 復習項目に紐づく復習管理情報（復習回分）をデータベースへ新規登録する。

#### 【処理概略】
- 入力値の復習回リストの件数分（5行）、REVIEW_MANAGEMENTテーブルへレコードを登録する。
- 登録した復習管理情報のリストを返却する。

## ○処理詳細

### 1. 復習管理情報登録

- (1) REVIEW_MANAGEMENTテーブルへ登録する。`review_time_list`（復習回）の件数分（5行）登録する。

  ```sql
  INSERT INTO review_management (
    user_id,     -- 復習管理情報．ユーザーID
    review_id,   -- 復習管理情報．復習項目ID
    review_time, -- 復習管理情報．復習回
    review_date, -- 復習管理情報．復習予定日
    done_flag,   -- 復習管理情報．対応済みフラグ
    created_at,  -- 復習管理情報．作成日
    updated_at   -- 復習管理情報．更新日
  ) VALUES (
    :user_id,
    :review_id,
    :review_time,
    :review_date,
    :done_flag,
    :today,
    :today
  );
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 登録内容 | ユーザーID | ○ | 入力値．ユーザーID | - |
  | 登録内容 | 復習項目ID | ○ | 入力値．復習項目ID | - |
  | 登録内容 | 復習回 | ○ | 入力値．復習回 | 1～5 |
  | 登録内容 | 復習予定日 | ○ | 入力値．復習予定日 | 入力値．復習回に対応する復習予定日 |
  | 登録内容 | 対応済みフラグ | ○ | False | - |
  | 登録内容 | 作成日 | ○ | 入力値．現在日時 | - |
  | 登録内容 | 更新日 | ○ | 入力値．現在日時 | - |
