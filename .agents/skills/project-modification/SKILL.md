# プロジェクト改修の考え方

- プロジェクト完了工程まで完了しているシステムの改修を行う場合、以下の手順で行う。

1. 実現したい目標に対する作業管理：`運用ルール/作業管理ルール/作業管理ルール.md`に従う
2. タスク毎の修正対象の洗い出し
    - 洗い出した修正対象は、タスク詳細ファイルの「## 修正対象資材」に記載する。
3. 影響範囲の洗い出し
    - 本修正により影響が出る資材を、同じくタスク詳細ファイルの「## 修正対象資材」に記載する
4. 修正・改修
    - `運用ルール/開発ルール/レビュー工程ルール.md`に従う。
