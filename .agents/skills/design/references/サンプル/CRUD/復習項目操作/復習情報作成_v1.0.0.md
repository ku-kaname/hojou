### 処理概要

#### 【目的】
- 復習情報をデータベースへ新規登録する。

#### 【処理概略】
- 入力値のユーザーIDに紐づく復習項目IDの最大値を取得し、+1した値を採番する。
- 採番した復習項目IDをもとにREVIEWテーブルへレコードを登録する。
- 登録した復習情報を返却する。

## ○処理詳細

### 1. 復習ID採番

- (1) 復習項目ID最大値を取得する。

  ```sql
  SELECT
    MAX(review_id)  -- 復習情報．復習項目ID
  FROM review
  WHERE
    user_id = :user_id;  -- 復習情報．ユーザーID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 復習項目ID | - | - | 最大値を取得 |
  | 検索条件 | ユーザーID | ○ | 入力値．ユーザーID | - |

### 2. 復習情報登録

- (1) REVIEWテーブルへ登録する。

  ```sql
  INSERT INTO review (
    user_id,      -- 復習情報．ユーザーID
    review_id,    -- 復習情報．復習項目ID
    review_item,  -- 復習情報．復習項目
    description,  -- 復習情報．復習内容詳細
    study_date,   -- 復習情報．学習日
    created_at,   -- 復習情報．作成日
    updated_at    -- 復習情報．更新日
  ) VALUES (
    :user_id,
    :review_id,
    :review_item,
    :description,
    :study_date,
    :today,
    :today
  );
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 登録内容 | ユーザーID | ○ | 入力値．ユーザーID | - |
  | 登録内容 | 復習項目ID | ○ | 復習ID採番．レスポンス +1 | - |
  | 登録内容 | 復習項目 | ○ | 入力値．復習項目 | - |
  | 登録内容 | 復習内容詳細 | - | 入力値．復習内容詳細 | - |
  | 登録内容 | 学習日 | ○ | 入力値．学習日 | - |
  | 登録内容 | 作成日 | ○ | 入力値．現在日時 | - |
  | 登録内容 | 更新日 | ○ | 入力値．現在日時 | - |
