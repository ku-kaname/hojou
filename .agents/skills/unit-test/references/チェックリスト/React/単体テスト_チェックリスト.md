# 単体テスト チェックリスト（React）

> **注記**：本チェックリストが対象とするReactは、公開版v1時点では動作未検証の技術スタックです。FastAPIを正式サポート対象とし、Reactでの動作確認が取れ次第、正式サポートへ格上げします。

## 列挙型定数・型定義への追随

- [ ] ステータス値・質問項目一覧など複数のコンポーネント・テストから参照される列挙型定数を変更した際、その定数を参照する全テストファイルを横断検索してから変更作業を完了としたか
- [ ] 新機能（F番号等）追加に伴い列挙型定数の値を拡張した際、既存の単体テスト仕様書・テストコードが拡張前の値のまま検証を続けていないか確認したか

## モックオブジェクトの型整合性

- [ ] テストコード内でAPIレスポンス・ブラウザ組み込みオブジェクトをモックする際、対応する型定義を必ず参照し、必須プロパティの過不足がないか確認したか
- [ ] テストコード作成後、テストランナーでの実行成功だけでなく`npm run build`（型チェック込みのビルド）が通ることも都度確認したか
