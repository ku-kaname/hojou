## フォルダ構成

以下はアプリケーション本体（`frontend/`・`backend/`以下）および開発プロセス成果物の構成。`hojou/`・`.claude/`・`AGENTS.md`・`CLAUDE.md`等の開発プロセス運用に関するファイルはプロジェクト横断的な構成のためここには含めない。

```
.
├── docker-compose.yml                              # フロントエンド・バックエンド各コンテナの起動定義
├── README.md                                       # プロジェクト概要・セットアップ・API一覧
│
├── frontend/                                       # フロントエンド本体（React・TypeScript）
│   ├── Dockerfile                                  # Nginx配信用のマルチステージビルド定義
│   ├── package.json                                # 依存パッケージ定義
│   ├── tsconfig.json                               # TypeScript設定
│   ├── vite.config.ts                              # Viteビルド設定
│   ├── index.html                                  # SPAのエントリーHTML
│   └── src/
│       ├── main.tsx                                # エントリーポイント
│       ├── App.tsx                                 # ルーティング定義
│       ├── api/                                    # バックエンドAPI呼び出し関数
│       │   └── client.ts
│       ├── pages/                                  # 画面単位のコンポーネント（S01〜S06に対応）
│       │   ├── LoginPage.tsx
│       │   ├── UserRegisterPage.tsx
│       │   ├── MyPage.tsx
│       │   ├── ReviewListPage.tsx
│       │   ├── ReviewCreatePage.tsx
│       │   └── AdminUserListPage.tsx
│       ├── components/                             # 画面共通の部品
│       ├── types/                                  # APIリクエスト・レスポンスの型定義
│       └── tests/                                  # 単体テストコード（Vitest + React Testing Library）
│           └── unit/
│               ├── <画面名>.test.tsx
│               └── ...
│
├── backend/                                        # バックエンド本体（Python パッケージ）
│   ├── Dockerfile                                  # Dockerイメージ定義
│   ├── pyproject.toml                              # Pythonプロジェクト設定・依存パッケージ定義
│   ├── requirements.txt                            # pip用の依存パッケージ一覧（自動生成）
│   ├── .env                                        # 環境変数（Gitに含めない）
│   │
│   └── app/                                        # アプリケーション本体（Python パッケージ）
│       ├── __init__.py                             # このファイルにより "app" は Python パッケージになる
│       ├── main.py                                 # エンドポイント定義（オーケストレーション層の呼び出しのみ）
│       ├── services.py                             # オーケストレーション層（ビジネスロジック・復習スケジュール自動生成等）
│       ├── auth.py                                 # JWT認証・トークン発行・有効ユーザー検証
│       ├── crud.py                                 # DB操作関数（Create / Read / Update / Delete）
│       ├── models.py                               # SQLAlchemy テーブルモデル定義（USER / REVIEW / REVIEW_MANAGEMENT）
│       ├── schemas.py                              # Pydantic スキーマ（リクエスト・レスポンス定義）
│       ├── database.py                             # DB接続・セッション管理・テーブル作成
│       └── tests/                                  # テストコード（Python サブパッケージ）
│           ├── __init__.py                         # このファイルにより "tests" は Python サブパッケージになる
│           ├── conftest.py                         # 全テスト共通フィクスチャ
│           ├── unit/                                # 単体テスト（モックを使用・DBに依存しない）
│           │   ├── test_<機能名>.py
│           │   └── ...
│           └── integration/                         # 結合テスト（SQLiteを使用）
│               ├── __init__.py                     # このファイルにより "integration" は Python サブパッケージになる
│               ├── conftest.py                     # 結合テスト共通フィクスチャ（テスト用DBセッション・TestClient等）
│               ├── test_<機能名>.py
│               └── ...
│
├── test_specification/                             # テスト仕様書
│   ├── unit_test_specification/                    # 単体テスト仕様書（バックエンド＋フロントエンド）
│   │   ├── evidence/                              # 単体テスト実施エビデンス（HTMLレポート）
│   │   ├── ユーザー操作/                           # バックエンド：crud/main等の単体テスト仕様書
│   │   ├── 復習情報操作/                           # バックエンド：crud/main等の単体テスト仕様書
│   │   └── 画面/                                   # フロントエンド：画面コンポーネントの単体テスト仕様書（S番号単位）
│   └── integration_test_specification/             # 結合テスト仕様書（バックエンドAPI対象）
│       ├── evidence/                              # 結合テスト実施エビデンス（HTMLレポート）
│       ├── ユーザー操作/
│       └── 復習情報操作/
│
├── 要件定義書/
│   ├── 概要.md                                     # 目的・背景・課題・想定利用者・システム構成・用語
│   ├── 業務要件.md                                  # 対象業務・業務の流れ・利用状況・成功基準・対象範囲・前提・制約
│   ├── 機能一覧.md                                  # 機能一覧
│   ├── 機能要件.md                                  # アクセス制御・業務ルール・扱うデータ・ファイル入出力・外部連携
│   ├── 非機能要件.md                                # 操作性・処理量・性能・可用性・セキュリティ・動作環境・テスト方針・運用・保守
│   ├── 技術スタック.md                              # 使用技術・ライブラリ一覧
│   ├── 判断根拠書.md                               # 技術・設計・運用の判断理由と採用しなかった候補の記録
│   ├── フォルダ構成.md                              # プロジェクトのディレクトリ構成（本ファイル）
│   └── 画面一覧.md                                  # 画面一覧（S番号・役割・対応機能）
│
├── 設計書/
│   ├── エンドポイント_v{バージョン}.md               # エンドポイント一覧（HTTPメソッド・URL）
│   ├── テーブル定義（models）_v{バージョン}.md       # DBテーブル定義（カラム・型・必須・制約）
│   ├── 画面/                                       # フロントエンド画面設計
│   │   └── UI仕様書/
│   │       ├── <画面名>_v{バージョン}.html          # 画面ごとのUI仕様書（モックアップ＋項目定義、HTML形式）
│   │       └── ...
│   ├── CRUD/                                       # DB操作（crud.py）の設計書
│   │   ├── ユーザー操作/
│   │   │   ├── <機能名>_v{バージョン}.md
│   │   │   └── ...
│   │   └── 復習情報操作/
│   │       ├── <機能名>_v{バージョン}.md
│   │       └── ...
│   ├── サーバー処理（main）/                        # エンドポイント処理フロー設計書（main.py）
│   │   ├── ユーザー操作/
│   │   │   ├── <機能名>_v{バージョン}.md
│   │   │   └── ...
│   │   └── 復習情報操作/
│   │       ├── <機能名>_v{バージョン}.md
│   │       └── ...
│   ├── スキーマ（schemas）/                         # リクエスト・レスポンスのスキーマ設計書
│   │   ├── ユーザー操作_v{バージョン}.md
│   │   └── 復習情報操作_v{バージョン}.md
│   └── 認証・認可（auth）/
│       ├── <機能名>_v{バージョン}.md
│       └── ...
│
└── レビュー指摘表/                                   # 各工程のレビュー指摘管理
    ├── 要件定義工程/
    │   └── <要件定義ファイルと同じフォルダ構成>/
    │       ├── <ファイル名>_レビュー指摘表.md
    │       └── ...
    ├── 設計工程/
    │   └── <設計書分類>/
    │       ├── <機能名>_v{バージョン}_レビュー指摘表.md
    │       └── ...
    ├── 実装工程/
    │   └── <実装ファイル名>/
    │       ├── <機能名>_v{バージョン}_レビュー指摘表.md
    │       └── ...
    ├── 単体テスト工程/
    │   └── <対象ファイル名>/
    │       ├── <機能名>_v{バージョン}_レビュー指摘表.md
    │       └── ...
    └── 結合テスト工程/
        ├── テスト仕様書レビュー/
        │   ├── ユーザー操作/
        │   └── 復習情報操作/
        └── テスト実施中/
            ├── ユーザー操作/
            └── 復習情報操作/
```
