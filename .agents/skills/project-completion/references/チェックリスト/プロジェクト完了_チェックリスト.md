## 完了判定の根拠

- [ ] 「全工程完了」「全指摘対応済み」と判定する根拠は、対応件数の多さではなく、各工程を独立した観点から再走査し新たな問題が出ないことを確認した結果になっているか
- [ ] レビュー指摘表への対応を「その時点で見つかっていた問題を解消したこと」として扱い、「他に問題が存在しないこと」の証明と混同していないか
- [ ] 直前に大量の指摘へ対応した場合、その安心感によって次の再鑑の網羅性・厳格さが緩んでいないか
- [ ] 完了資料（README.md、引継ぎ資料等）に記載する件数・状態が、レビュー指摘表・作業管理・引継ぎ資料の間で一致しているか
