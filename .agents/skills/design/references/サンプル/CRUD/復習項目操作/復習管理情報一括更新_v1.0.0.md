| メソッド論理名 | 復習管理情報一括更新 |
| メソッド物理名 | update_all_review_management |

### 処理概要

#### 【目的】
- 復習項目に紐づく全ての復習管理情報を一括で更新する。

#### 【処理概略】
- 入力値のユーザーID・復習項目IDに紐づく復習管理情報を、復習回を条件に含めずREVIEW_MANAGEMENTテーブルで一括更新する。
- 更新後の復習管理情報リストを返却する。

## ○処理詳細

### 1. 復習管理情報一括更新

- (1) REVIEW_MANAGEMENTテーブルを一括更新する。

  ```sql
  UPDATE review_management
  SET
    done_flag = :done_flag,  -- 復習管理情報．対応済みフラグ
    updated_at = :today       -- 復習管理情報．更新日
  WHERE
    user_id = :user_id        -- 復習管理情報．ユーザーID
    AND review_id = :review_id;  -- 復習管理情報．復習項目ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | 対応済みフラグ | ○ | 入力値．対応済みフラグ | - |
  | 更新内容 | 更新日 | ○ | 入力値．現在日時 | - |
  | 検索条件 | ユーザーID | ○ | 入力値．ユーザーID | - |
  | 検索条件 | 復習項目ID | ○ | 入力値．復習項目ID | - |

  ※復習回を検索条件に含めないことで、ユーザーID、復習項目IDに紐づく全ての復習回分（5行）を更新する。
