# 結合テスト チェックリスト（FastAPI）

## テストケースの網羅

**バリデーション異常系（HTTP 422）**
- [ ] 必須パラメータが欠落した場合の HTTP 422 テストケースを作成しているか
- [ ] 型不一致・桁数オーバーの場合の HTTP 422 テストケースを作成しているか

**実装の挙動確認**
- [ ] URLパスパラメータが `main.py` のエンドポイント関数引数で宣言されているか確認し、宣言されていない場合は「無視される」挙動を確認するテストケースを作成しているか
- [ ] `main.py` の条件分岐を全て確認し、全分岐にテストケースが対応しているか

## テスト専用データベースの分離

- [ ] テスト専用データベースを分離する際、DB名の分離だけで満足せず、接続ユーザーの権限自体を対象データベースへ限定できないか検討したか
- [ ] 同一サーバー上に本番相当DBとテスト専用DBを同居させる構成の場合、名前による防御だけでなくサーバー自体の分離も選択肢として検討したか
- [ ] DB分離の対策を実施した後、その対策が防ぎきれていない別のリスク（接続ユーザー権限等）が残っていないか振り返ったか

## 入力値検証テストの網羅性

- [ ] ファイルアップロードエンドポイントの結合テストに、サイズ上限超過・拡張子不正・デコードエラー・空値の各ケースを含めたか
- [ ] 同じ論理データを複数の入力経路（フォーム直接入力・ファイルアップロード等）で受け付けるエンドポイントでは、両経路に同じ入力値検証のテストケースを適用したか
