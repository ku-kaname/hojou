# 結合テスト Codex指摘・再鑑時チェックリスト（React）

> **注記**：本チェックリストが前提とするCodex運用は、公開版v1時点では動作未検証の実験的機能です。Claude運用を正式サポート対象とし、Codexでの動作確認が取れ次第、正式サポートへ格上げします。
>
> **注記**：本チェックリストが対象とするReactについても、公開版v1時点では動作未検証の技術スタックです。FastAPIを正式サポート対象とし、Reactでの動作確認が取れ次第、正式サポートへ格上げします。

## 既存テストとの責務重複確認

- [ ] 画面遷移・分岐が未検証と指摘する前に、同じ分岐を実`apiClient`等を通して直接検証する単体テストが既に存在しないか横断検索したか
- [ ] 下位階層（単体テスト）で契約が直接かつ安定して検証済みの場合、結合テスト（`MemoryRouter`等を使う画面遷移テスト）へ同じ検証の重複追加を必須としていないか

## 実際に発生した指摘ミス（要約）

認証・保護ルート結合の結合テスト仕様書で、ログイン401と保護API 401の分岐が未検証と指摘したが、当該分岐の実装は既に存在し、実`apiClient`を通す単体テスト3件で直接検証済みだった。`MemoryRouter`を使う当該結合テストで重複追加する責務でもなかった。
