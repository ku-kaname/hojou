## 機能ごとのエンドポイント
|機能|HTTPメソッド|エンドポイント|備考|
|---|---|---|---|
| ホーム | GET | / | 認証不要 |
| ヘルスチェック | GET | /health-check | 認証不要 |
| トークン発行 | POST | /token | 認証不要 |
| ユーザー作成 | POST | /users | 認証不要 |
| 全ユーザー取得 | GET | /users | 要Bearer認証 |
| 特定ユーザー取得 | GET | /users/{user_id} | 要Bearer認証 |
| ユーザー情報更新 | PUT | /users/{user_id} | 要Bearer認証 |
| ユーザー削除 | DELETE | /users/{user_id} | 要Bearer認証 |
| 復習項目作成 | POST | /users/{user_id}/reviews | 要Bearer認証 |
| 復習項目取得 | GET | /users/{user_id}/reviews | 要Bearer認証 |
| 復習項目更新 | PATCH | /users/{user_id}/reviews/{review_id} | 要Bearer認証 |
| 復習項目削除 | DELETE | /users/{user_id}/reviews/{review_id} | 要Bearer認証 |
